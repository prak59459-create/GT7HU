# Project Racing Simulator

ブラウザで動作する本格3Dレーシングシミュレーター。Vite + TypeScript + Three.js 構成。

## Phase 1 完成要件（計画書 §19）

> 完了条件：実際に走り、曲がり、止まり、何度も周回できる。

### 実装内容
- **物理エンジン**: 120Hz固定タイムステップ、4輪独立モデル
  - エンジン（トルクカーブ・レブリミット・エンジンブレーキ）
  - トランスミッション（6MT/AT・ギア比・クラッチ・シフト時間）
  - タイヤ（Pacejka Magic Formula・縦横複合スリップ・負荷依存）
  - サスペンション（ロール・ピッチ・荷重移動・ダウンフォース）
  - ブレーキ（前後バランス・ABS・ハンドブレーキ）
  - LSD（1.5way・加速/減速ロック）
  - 駆動方式別挙動（FR実装、データ駆動でFF/MR/RR/4WD対応）
- **3D描画**: PBR（クリアコート塗面・金属・ガラス）・動的シャドウ・PMREM環境反射・ACESトーンマッピング
- **車両メッシュ**: ロフト生成の高品質ボディ・グリーンハウス・5本スポークホイール・ブレーキディスク/キャリパー・ライト類・ウイング・ディフューザー・ミラー・マフラー
- **コース**: Aurora Valley GP Circuit（架空・約3.3km・高低差7m）— 路面・縁石・ガードレール・ポール・スタートガントリー・観客席・樹木・地形
- **カメラ**: チェイス/遠チェイス/ボンネット/バンパー/コックピット（C切替、速度連動FOV・揺れ）
- **HUD**: アナログタコ円弧・デジタル速度・ギア・シフトランプ・ラップ/ベスト/前回・ミニマップ・Gメーター
- **操作**: キーボード（WASD/Space/Shift/Ctrl）・Gamepad API（アナログスティック+トリガー）・ハンドル基本対応
- **サウンド**: Web Audio API合成エンジン音（RPM・スロットル連動）・スキール・風切り・シフト/衝突/カウントダウン
- **レース**: カウントダウン・ラップ計測・セクター バリデーション・ベストラップ・ポーズ/リスタート/設定

## Phase 2 実装内容

> 計画書 Phase 2: レース機能（AI対戦車・周回レース・順位・リザルト）。

- **左右操作の修正**: ステア入力と3D画面の方向が逆になっていたバグを修正（物理側のステア符号規約を統一。ミニマップの左右鏡像・車両マーカーの後ろ向きも同時に修正）
- **モード選択**: タイトル画面で FREE RUN（従来のタイムアタック）と RACE を選択可
- **AI対戦車**: 架空ライバル5台（Vectra S-R / Kessel GT / Noir RZ・架空ドライバー名）
  - ピュアパースート・ステアリング＋曲率ベース速度計画（制動先読み）
  - 難易度 EASY / NORMAL / HARD（コーナリング能力・トップ速度が変動）
  - 前車回避ステア・スタック自動復帰・軽度ラバーバンド（±数%）
  - プレイヤーと同一 VehiclePhysics / 同一120Hzタイムステップで更新（フェアネス担保）
- **レース進行**: 6台グリッドスタート（プレイヤーP6）→カウントダウン→規定周回（1/3/5選択）→フィニッシュ→リザルト
- **順位表示**: HUDに P n/6 と前車ギャップ（秒）、ミニマップにAI車両マーカー（車体色）
- **リザルト画面**: 順位・車両・総合時間/ギャップ・ベストラップ（最速は★表示）・RESTART/TITLE

## Phase 3 実装内容

> 計画書 Phase 3: 車両システム（ガレージ・ディーラー・チューニング・経済・セーブ）。

- **購入可能車両 8種**（架空ブランド6社・すべて架空車両: PART 21準拠）
  - FF: Kestrel City GT（990kg・約111PS・¥2,800,000）/ Kestrel City RS（約185PS・¥4,600,000）
  - FR: Noir RZ（軽量NA・約278PS・¥6,200,000）/ Aurora RS-2（初期贈呈・約379PS・¥8,800,000）/ Vectra S-R（高回転・約398PS・¥9,600,000）/ Kessel Automobil GT（重厚GT・約398PS・¥12,800,000）
  - 4WD: Halberd Terra 4（ラリーベース・約290PS・¥10,500,000）
  - MR: Lumiere Veloce（フラッグシップ・約555PS・¥28,000,000）
- **ガレージ**: 所有車リスト / 3Dショールーム（スタートライン上でOrbitカメラが回転展示）/ スペック表示（最高出力・最大トルク・車両重量・パワーレシオ）/ 色変更 / お気に入り / 売却（車両+チューニング投資額の60%還元）
- **ディーラー**: 8車種ブラウズ（所有済み表示）/ クレジット購入
- **チューニングショップ**: 7カテゴリ×最大3段階の段階式パーツ
  - エンジン（トルク+8/16/26%）/ タイヤ（μ+0.04/0.09/0.15）/ サスペンション（バネ・ダンパー+20/45%）/ ブレーキ（制動+18/40%）/ エアロ（ダウンフォース+20/45%）/ 軽量化（-25/-55/-90kg）/ ドライブトレイン（シフト短縮・ファイナル）
  - 導入は段階順（STAGE1→2→3）、ストックへ戻し可（返金なし）
  - 適用結果はスペック表示と実走行の双方へ即反映（VehiclePhysicsSpecへ適用）
- **経済システム**: クレジット / レース報酬（順位×周回数×難易度: P1=1,000,000+220,000/lap基準、NORMAL×1.6、HARD×2.2）/ 初期贈与 3,000,000Cr + Aurora RS-2
- **セーブ**: localStorage（`racing-sim-profile-v1`）自動保存 — クレジット・所有車・カラー・お気に入り・チューニング・戦績が次回起動時に復元。file:// でも機能

## Phase 4 実装内容

> 計画書 Phase 4: ゲームコンテンツ（タイムトライアル・ライセンス・ミッション・ドリフト・進行管理）。
> 目標値は実物理のヘッドレス計測（0-100km/h 7.33s / 制動 100km/h→53.7m / AIラップ normal 72.6s 等）に基づき調整。

- **タイムトライアル (TT)**: 周回無制限のタイムアタック。ベストラップはプロフィールに永続記録され、
  メダル目標（BRONZE 85s / SILVER 78s / GOLD 72s）達成ごとに報酬（20万/40万/70万Cr・上位差分支給）。
- **ドリフトトライアル (DT)**: 2周のスコアアタック。
  - 車体スリップ角10°以上・25km/h以上・路面上をドリフトと判定
  - スコアレート = 角度×速度、連続ドリフトでコンボ倍率（最大×3）を蓄積
  - 目標 1000 / 2000 / 3500 PTS（BRONZE/SILVER/GOLD）
- **ライセンスセンター**: 8課題（B→A の順に解放。bronze以上で合格）
  | コード | 課題 | 目標 (B/S/G) |
  |---|---|---|
  | B-1 | 加速テスト 0-100km/h | 9.0 / 7.5 / 6.5 s |
  | B-2 | 制動テスト（停止ゾーン+200〜245m） | 45 / 12 / 4 m（ライン手前距離） |
  | B-4 | セクター1走破（約680m） | 34.0 / 31.5 / 29.0 s |
  | B-6 | 1周タイム | 90 / 85 / 80 s |
  | A-2 | ドリフト訓練（1周のスコア） | 400 / 700 / 1100 PTS |
  | A-4 | クリーンラップ（コースアウト即失格） | 88 / 84 / 79 s |
  | A-6 | トップスピード | 150 / 165 / 180 km/h |
  | A-8 | デュエル（NORMALライバル1台・1周・勝利で合格、勝ち差でメダル） | 0 / 0.8 / 2.0 s |
- **ミッション**: 8種（順次解放・単一ゴール・初回クリア全額/再クリア10%報酬）
  - M-1 ファーストヴィクトリー（EASY×1・1周デュエル勝利）/ M-2 スピードハンター（160km/h）
  - M-3 ドリフトキング（1周800PTS）/ M-4 パーフェクトライン（クリーン1周80s以内）
  - M-5 ダブルデュエル（NORMAL×2・2周P1）/ M-6 ドリフトマスター（2周2000PTS）
  - M-7 エンデュランスクリーン（3周ノーアウト・合計240s以内）/ M-8 グランドファイナル（HARD×2・3周P1）
- **進行管理**: ライセンスメダル・ミッション達成・TT/DT記録はすべて localStorage プロファイルに保存
  （旧Phase 3セーブから自動移行）。タイトル画面に LIC n/8 · MIS n/8 の達成数を表示。
- **UI**: チャレンジセンター（ライセンス/ミッション/トライアルの3タブ・メダルバッジ・ロック表示・
  目標/報酬/ベスト表示）、走行中HUDに課題名・進行値・目標パネル、リザルトにメダル表示。
- **実行時評価エンジン (ChallengeRunner)**: 種別ごとの成功/失敗（コースアウト・オーバーラン・速度不足等は即失格）、
  メダル判定、ドリフトスコアリングを120Hz物理と同タイミングで評価。タイム計測はGOから開始
  （カウントダウンを含まない）。プレイヤーの使用車両・チューニングがそのまま適用される。
- **デュエル**: RaceManager が AI台数を可変対応（rivalCount=1〜5）。プレイヤーは最後尾グリッド。

## 実行方法

### 開発（Vite dev server）
```bash
npm install
npm run dev
```

### ビルド（単一HTML）
```bash
npm run build
```
→ `dist/index.html` にJS/CSS完全インライン化。file:// でダブルクリック起動可能。

### GitHub Pages
main ブランチへ push で Actions が自動ビルド→Pages デプロイ。
リポジトリ Settings → Pages → Source = "GitHub Actions" に設定済みであること。
